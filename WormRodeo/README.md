# Worm Rodeo

This project is a token launch initiative designed with built-in capability for integration with the Wormhole protocol. The goal is to facilitate seamless cross-chain transfers of the launched token.

## Project Structure

The project is organized into the following main directories:

*   `contracts/`: This directory will contain the smart contracts for the token itself and any related logic, including the hooks or interfaces for Wormhole integration.
*   `scripts/`: This directory will house scripts for deploying the contracts, interacting with them, and potentially managing the Wormhole integration process.

## Features

*   Standard token implementation.
*   Designed with Wormhole integration in mind for cross-chain compatibility.
*   Clear separation of contract code and deployment/interaction scripts.
